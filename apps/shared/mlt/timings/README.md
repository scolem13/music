Timing maps for the MLT / JRI recordings: Timestamp Notes song files, one per recording, named `<recording id>.json`
(the name Timestamp Notes suggests when it was opened with `?rec=<id>`). After adding one, run
`node scripts/mlt-recordings.mjs` so recordings.js marks the recording `timing: 1`. Read by Timestamp Notes (`?rec=`) and the
Chord Grid by Ear (`practice/ear-grid.qmd`).
