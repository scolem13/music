- MLT Books (top-level section `mlt/`: the MLT teaching books walked through step by step, not reproduced: each step has page citations, what the book prints there (names, sets), the teacher's summary and a student activity; Teacher / Student view, `?view=student`): engine `apps/shared/mlt/mlt-walk.js` (step format in its header), books `apps/shared/mlt/books/<id>.js` (Mullen Du…De: chapters 12-13 and Units 1-10 entered; next JRI Recorder, DMTI 1-3, Music Play, later JRI Elementary; Mullen pages from the line-to-PDF-page map `research_notes/mlt-sources/text/MLTAnyMusicTeacherCanDuDe.pages.txt`, made by `swift research_notes/mlt-pagemap.swift`; PDF page = print page in that book), classroom activities database `apps/shared/mlt/activities.js` (page `mlt/activities.qmd`, filterable). Read from the text cache (`research_notes/mlt-sources-INDEX.md`). DMTI 1-3 (`mlt/dmti.qmd`): steps from one template in `books/dmti.js`, exercises (Seven Skills, series, antecedent/consequent) generated from the unit's tune + rhythm set + tonal set by `apps/shared/mlt/dmti-skills.js` (test `node tests/mlt/dmti-skills.test.js`, `NEG=1` must fail); three units wait for DMTI's own tunes (`todo` in books/dmti.js). Student home practice on sax (`practice/sax-home.qmd`, `apps/shared/mlt/sax-home.js`: the class's JRI-on-sax sequence at home: songs (plus pool tunes so each lesson has major/minor, duple/triple), new notes, echo patterns checked by microphone, rhythm on RhythmChant, articulation, songs playable with the notes known, home activities, the sax lesson's holding/embouchure/tone/tuning/care notes; tonality and meter established first by `apps/shared/mlt/establish.js` (ways from the MLT books, picked by weight; `Establish.WEIGHTS` from the teacher's weights page https://claude.ai/artifact/VRnxGL7PMFtRAoeMTPbxPB, test `node tests/mlt/establish.test.js`); tests `node tests/mlt/sax-home.test.js`, `tests/mlt/sax-home.cdp.js`). Lesson planner (`mlt/lesson-builder.qmd`, `apps/shared/mlt/lesson-builder.js`: plan from a unit + activities, run with a timer, class screen in a second window over BroadcastChannel, activity lengths and class-screen types from `mins` / `screen` in activities.js, LSA record sheet after Mullen pp. 83–84 in `record-sheet.js`; tests `node tests/mlt/lesson-builder.test.js`, `node tests/mlt/record-sheet.test.js`, `tests/mlt/lesson-builder.cdp.js`; plan and what is left: `research_notes/mlt-lesson-builder-plan.md`). Rote Song by Ear (`mlt/rote-song.qmd`, `apps/shared/mlt/rote-song.js`, global RoteSong: Mullen's Rote Song Procedure pp. 90–91 as nine steps with Next / Back, no notation; step 8 "Audiate the ending" is the site's: the song cut in its last quarter, Space timed against the last note; the 👂 by-ear button on every unit's song list; uses `AbcPlay` `onStart` / `fromMs` / `untilMs`; test `tests/mlt/rote-song.cdp.js`). Tests `node tests/mlt/mlt-data.test.js` (`NEG=1` must fail), `tests/mlt/mlt-walk.cdp.js`
- MLT / JRI recordings (the book CDs in ~/Music/MLT, hosted for the students in R2 with permission; never the Edwin E. Gordon Test): `node scripts/mlt-recordings.mjs` reads the tags and writes the catalogue `apps/shared/mlt/recordings.js` (global MLTRecordings) and `research_notes/mlt-recordings-manifest.tsv`; `MLT_R2_BUCKET=<bucket> node scripts/mlt-recordings.mjs --upload` sends new files (wrangler via npx, done-list in ~/.cache). Listed by CD on the Tune Directory (section `#td-mlt`, a name plays it in place). Each recording also has kind (song, accompaniment, tonal/rhythm/melodic patterns, instructions …, `KINDS`), tonality, meter, key and `tune` (tune collection ids, matched by title; `guess` lists fields read off the tune, not checked); hand-checked facts in `apps/shared/mlt/recordings-meta.json`, edited on the Recordings Catalogue (`mlt/recordings.qmd`, `rec-catalogue.js`: edits kept in the browser until downloaded, then rerun the script). Timing maps: Timestamp Notes song files at `apps/shared/mlt/timings/<id>.json` (Timestamp Notes `?rec=<id>` opens the recording and its map, saves under that name). `MLTRecordings.forTune(id)` feeds the Tune Library panel (`Works.mltPart`), the 🎧 button on MLT song lists (both views) and the Chord Grid by Ear (`practice/ear-grid.qmd`, `apps/shared/mlt/ear-grid.js`: blank bars from the timing map or a steady tempo, guesses checked by function against the linked tune's chords, notation in the recording's key). Tests `node tests/mlt/ear-grid.test.js` (`NEG=1` must fail), `tests/mlt/rec-links.cdp.js`. Bucket `everything-music-mlt`, served at https://media.seancoleman.org (`window.MLT_REC_BASE` in `_includes/head.html`).
- MLT blogs as books (links only, own-words summaries, used with the authors' permission): Shouldice's Everyday Musicality podcast + Research to Real Life blog (`mlt/shouldice.qmd`, `books/shouldice.js`, 151 posts; each step says Post read / Show notes / Title only) and Bluestine's Substack (`mlt/bluestine.qmd`, `books/bluestine.js`, guest spots in its `guests` unit) and Rasmussen & Taillefer's podcast Audiation in the Wild (`mlt/rasmussen.qmd`, `books/rasmussen.js`, 108 episodes from the RSS feed; every episode step has `transcript: url | false`); steps use `href` and `xref` (mlt-walk.js).
