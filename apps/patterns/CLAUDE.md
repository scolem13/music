# Patterns and the by-Ear tools

(Moved from the root CLAUDE.md 2026-11-27.)

- Tonal Patterns / Tonal Sequences (`practice/_patterns-embed.qmd`, `_tonal-sequences-embed.qmd`; data `apps/patterns/pattern-set.js`, notes written zero-length `C0`): play bar `apps/patterns/pattern-play.js`, set generator `apps/patterns/pattern-gen.js` (its header lists the rules read off the hand-written sets; made sets kept in localStorage as ★). Tests `node tests/patterns/pattern-gen.test.js`, `tests/patterns/patterns.cdp.js`. Patterns by Ear (`practice/patterns-by-ear.qmd`, `apps/patterns/ear-piano.js`: piano, MIDI in via MidiFeel, no notation; fingering is a rule of thumb, unverified): `node tests/patterns/ear-piano.test.js`, `tests/patterns/ear-piano.cdp.js`
- Hearing Harmony (`practice/harmony-ear.qmd`, `apps/patterns/harmony-ear.js`: progressions by ear on bass + piano, no mic; paths MLT / rock / jazz / classical / custom, each a list of levels; chord tokens are Roman numerals from the resting tone, format in the header). Plan for the rest of the MLT ear tools: `research_notes/ear-training-plan.md`. Tests `node tests/harmony/harmony-ear.test.js`, `tests/harmony/harmony-ear.cdp.js`
- Bass Lines by Ear (`practice/bass-ear.qmd`, `apps/patterns/bass-ear.js`: melody + a made-up bass line, then a bass line alone, same or different; styles mlt / rock / jazz / classical with their embellishments, levels 1-9 (1 = chord roots only), "Bass on" changes / bars / macrobeats / beats / chance; header lists the kinds of difference; notation by `BassEar.abc`, bar lengths checked for every tune in the test). Tunes: `apps/patterns/bass-ear-tunes.js`, written by `node scripts/bass-ear-corpus.mjs` (rerun after the tune collection changes). Tests `node tests/bass-ear/bass-ear.test.js`, `tests/bass-ear/bass-ear.cdp.js`
- Odd Progression Out (`practice/prog-ear.qmd`, `apps/patterns/prog-ear.js`: three clips, two the same progression in two band styles, one slightly different in a third; band levels 1-8 (inversions, sevenths, extensions count as same; diffs far / rel / mode / chrom), melody-line levels m1-m5 (more non-chord tones); all eight Gordon tonalities (MODAL); "Borrowed chords" off by default = diatonic reharmonisation that keeps the melody notes (reharm, IV(add9) gospel 9th); "A tune on top" = one shared melody over the band; Busyness full / less / calm swaps in plainer band parts (busyOpts); options grouped The question / The band / Notation; notation of block voicings or the melody any time; header has the formats). Uses AbcPlay `drums:false`, `melody:false`. Tests `node tests/prog-ear/prog-ear.test.js`, `tests/prog-ear/prog-ear.cdp.js`
- Blues Changes by Ear (`practice/blues-ear.qmd`, `apps/patterns/blues-ear.js`: the Odd Progression Out page on the 12-bar blues, run through `ProgEar.mount`; a version is a set of CHOICES (quick change, bar 4 ii–V, #iv°7, VI7, bars 9–10, turnarounds, tritone subs, backdoor, Bird, minor blues), the odd clip changes one; levels 1-8 and m1-m3; Bars: the phrase with the change (default), any four, all 12, or chosen; forms unverified). Tests `node tests/blues-ear/blues-ear.test.js`, `tests/blues-ear/blues-ear.cdp.js`
