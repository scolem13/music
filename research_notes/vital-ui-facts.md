# Vital synth: user interface and workflow facts (for beginner lessons)

Read on 2026-11-27 from the GPLv3 source at github.com/mtytel/vital (raw.githubusercontent.com/mtytel/vital/main/...,
file list from api.github.com/repos/mtytel/vital/git/trees/main?recursive=1) and from https://vital.audio and
https://forum.vital.audio. Every line gives its source. Paths are relative to the repo root.

Caveats that apply to everything below:
- README.md: "This repository is updated on a delay after binary releases." So the shipping plug-in may differ from this source.
- The source build is branded "Vial", not "Vital" (plugin/vital.jucer `pluginName="Vial"`; common/load_save.cpp data folder `"Vial"`), because README.md forbids using the name "Vital" for source builds. Text that the real plug-in shows is only confirmed where the string is in the source.
- "Cmd" below: the code tests JUCE `isCommandDown()` (src/interface/editor_components/synth_slider.cpp, line_editor.cpp). In JUCE that is Cmd on macOS and Ctrl on Windows/Linux. That JUCE meaning is from my knowledge of JUCE, not read in this repo (see Unconfirmed).
- UI labels are drawn in capitals in the plug-in (`drawLabelForComponent(g, TRANS("MIX"), ...)`); menu items use the mixed-case strings from src/interface/look_and_feel/synth_strings.h.

## 1. Window and tabs

- Four header tabs, in this order: VOICE, EFFECTS, MATRIX, ADVANCED. — src/interface/editor_sections/header_section.cpp, `tab_selector_->setNames({"VOICE", "EFFECTS", "MATRIX", "ADVANCED"});` (range 0..3).
- Tab 0 (VOICE) shows the synthesis interface (oscillators, sample, filters); tab 1 shows the effects; tab 2 shows the modulation matrix; tab 3 shows the "master controls" (advanced) panel. — src/interface/editor_sections/full_interface.cpp, `FullInterface::tabSelected` (`synthesis_interface_` index==0, `effects_interface_` index==1, `modulation_matrix_` index==2, `master_controls_interface_` index==3).
- The LFO / envelope / random / macro / keyboard-modulation area, the keyboard, the bend section, portamento section and voice section stay visible under every tab; only the preset browser or bank exporter hides them. — full_interface.cpp (`addSubSection` for `modulation_interface_`, `keyboard_interface_`, `bend_section_`, `portamento_section_`, `voice_section_`; `setPresetBrowserVisibility` hides modulation_interface_, portamento_section_, voice_section_, synthesis_interface_). (The claim "visible under every tab" is inferred from `tabSelected` not touching them; see Unconfirmed.)
- Header layout: logo button at left (click opens the About section), then the tab selector, then a centred preset selector (preset name with prev / next arrows, a Save button, a Menu button), then a VOLUME section with peak meters, and an oscilloscope at the right with a button to switch it to a spectrogram. — header_section.cpp (`LogoSection::buttonClicked` -> `showAboutSection`; `synth_preset_selector_`, `volume_section_`, `oscilloscope_`, `spectrogram_`, `view_spectrogram_`).
- Opening the preset browser replaces the tab strip with a "temporary tab" titled PRESET BROWSER and an X (exit) button; the bank exporter does the same with EXPORT BANK. Clicking X returns to the previous tab. — full_interface.cpp `setPresetBrowserVisibility` (`header_->setTemporaryTab("PRESET BROWSER")`), `setBankExporterVisibility` (`"EXPORT BANK"`); header_section.cpp `exit_temporary_button_` -> `clearTemporaryTab`.
- Counts: 3 oscillators, 1 sample, 2 filters, 8 LFOs, 6 envelopes, 4 random LFOs, 4 macros, 64 modulation connections, max polyphony constant 33 (32 active). — src/common/synth_constants.h (`kNumOscillators = 3`, `kNumFilters = 2`, `kNumLfos = 8`, `kNumEnvelopes = 6`, `kNumRandomLfos = 4`, `kNumMacros = 4`, `kMaxModulationConnections = 64`, `kMaxPolyphony = 33`, `kMaxActivePolyphony = 32`).
- Oscillator panels are titled "OSC 1" .. "OSC 3". — oscillator_section.cpp constructor `SynthSection(String("OSC ") + String(index + 1))`.
- Voice-tab sections: filter 2 and filter 1 sections are created (`FILTER 1`, `FILTER 2`), three `OscillatorSection`s, and a `SampleSection("SMP")`. — src/interface/editor_sections/synthesis_interface.cpp.
- The envelopes / LFOs / randoms are each a set of numbered tab buttons plus one editor shown at a time; panel titles "ENVELOPE n", "LFO n", "RANDOM n". — modulation_interface.cpp (`"ENVELOPE " + string_num`, `"LFO " + string_num`, `"RANDOM " + string_num`; `envelopes_[i]->setVisible(i == 0)`).

## 2. Header, presets, saving

- Preset name box shows "Init Preset" when the preset has no name; a leading `*` means modified. — src/interface/editor_components/synth_preset_selector.cpp `resetText()` (`TRANS("Init Preset")`, `"*" + preset_text`) and `setModified`.
- Clicking the preset name toggles the preset browser (left click); right-click on the name opens the menu. Prev / next arrows load the previous / next preset. — synth_preset_selector.cpp `textMouseUp` (`e.mods.isPopupMenu()` -> `showPopupMenu`, else `setPresetBrowserVisibile(!browser_->isVisible())`), `prevClicked`, `nextClicked`.
- Menu button (three-line icon) menu, in order: Browse Presets, Save Preset, Open External Preset, Export Preset, Import Bank, Export Bank, (separator), Initialize Preset, (separator), Load Tuning File, [Clear Tuning: name, only if a tuning is loaded], (separator), Log in / Log out, [Load Default Skin, only if a default skin exists]. — synth_preset_selector.cpp `showPopupMenu`.
- Alt-click on the Menu button opens a different menu: Open Skin Designer, Load Skin, [Load Default Skin]. — synth_preset_selector.cpp `buttonClicked` (`isAltDown()` -> `showAlternatePopupMenu`).
- "Init" preset = menu item "Initialize Preset": calls `loadInitPreset()` which rebuilds the engine with default parameter values, then resets the browser selection and the name text. — synth_preset_selector.cpp `initPreset()`; src/common/synth_base.cpp `SynthBase::loadInitPreset()` (`initEngine(); LoadSave::initSaveInfo(save_info_)`).
- What the Init preset contains (parameter defaults): oscillator 1 on (`osc_1_on` default overridden to 1; oscillators 2 and 3 off, default 0); osc 2 destination = index 1 (Filter 2), osc 3 destination = index 3 (Effects), osc 1 destination default 0 (Filter 1); filter 1 takes osc 1 (`filter_1_osc1_input` = 1), filter 2 takes osc 2 (`filter_2_osc2_input` = 1); filters themselves default off (`filter` parameter "on" default 0); all effects default off (`delay_on`, `distortion_on`, `reverb_on`, `phaser_on`, `flanger_on`, `chorus_on`, `compressor_on`, `eq_on` all default 0); sample off (`sample_on` default 0); polyphony 8; pitch bend range 2; portamento time -10 (its minimum); legato off; velocity track 0; unison voices 1; osc level 0.7071 (quadratic); osc wave frame 0; spectral morph type 0 (none), distortion type 0 (none). — src/common/synth_parameters.cpp (`ValueDetailsLookup` constructor overrides near `details_lookup_["osc_1_on"].default_value = 1.0f;` and the parameter lists).
- Envelope defaults: attack 0.1495, decay 1.0, sustain 1.0, release 0.5476 (parameter values on the quartic scale, not seconds). — synth_parameters.cpp `env_parameter_list` entries "attack", "decay", "sustain", "release". (The seconds these correspond to are not computed here.)
- Voice priority default is round robin (`VoiceHandler::kRoundRobin`); voice override default is kill (`kKill`). — synth_parameters.cpp `voice_priority`, `voice_override` rows.
- The wavetable name box of a freshly initialised oscillator shows "Init" after "Initialize" is chosen from the wavetable's right-click menu. — oscillator_section.cpp `loadDefaultWavetable()` (`preset_selector_->setText("Init")`). What the default wavetable looks like is not stated in the files read (see Unconfirmed).
- Save: the Save icon next to the name (or menu "Save Preset") opens the save section with fields NAME, AUTHOR, COMMENTS and buttons Save / Overwrite / Cancel; the style (below) is chosen there too; file-name characters `<>?*/|\[]":` are removed. — src/interface/editor_sections/save_section.cpp (`save_button_` "Save", `overwrite_button_` "Overwrite", `cancel_button_` "Cancel", `preset_text_` "NAME", `author_text_` "AUTHOR", `style_text_` "STYLE", `comments_text_` "COMMENTS", `overwrite_text_` "Overwrite existing file?", `FileNameInputFilter`); synth_preset_selector.cpp `savePreset()`.
- Preset styles (tag buttons): Bass, Lead, Keys, Pad, Percussion, Sequence, Experiment, SFX, Template. — src/interface/look_and_feel/synth_strings.h `kPresetStyleNames`; preset_browser.cpp creates one toggle button per name.
- Preset browser: columns Name, Style, Author, Date, plus a star column (favourites); a Search box; style filter buttons; a folder list; a Comments box. Escape closes it; Up / Left arrow loads previous, Down / Right loads next preset. Right-click on a preset: Open File Location, Rename, Delete (rename / delete not offered for every preset). — src/interface/editor_sections/preset_browser.cpp (`g.drawText("Name"...`, "Style", "Author", "Date"; `Paths::star()`; `search_box_` "Search"; `PresetBrowser::keyPressed`; `options.addItem(kOpenFileLocation, "Open File Location")`, `kRename`, `kDelete`).
- Preset file extension `.vital`; wavetable `.vitaltable` (also `.wav`, `.flac` can be loaded as wavetables); sample `.wav` / `.flac`; skin `.vitalskin`; LFO `.vitallfo`; bank `.vitalbank`. — src/common/synth_constants.h (`kPresetExtension`, `kWavetableExtension`, `kWavetableExtensionsList`, `kSampleExtensionsList`, `kSkinExtension`, `kLfoExtension`, `kBankExtension`).
- User data folder (source build): Windows `Documents/Vial`, macOS `~/Music/Vial`, Linux `~/.local/share/vital/` (or `$XDG_DATA_HOME/vial`); subfolders `Presets`, `Wavetables`, `Samples`, `Skins`, `LFOs`, with the user's own files under a `User` subfolder. The release build uses "Vital" in the folder name per the product name, but that is not in the source (see Unconfirmed). — src/common/load_save.cpp (`getDataDirectory`, `kUserDirectoryName = "User"`, `kPresetFolderName = "Presets"`, `kWavetableFolderName = "Wavetables"`, `getUserPresetDirectory`).
- Volume: a VOLUME slider with left / right peak meters in the header; the parameter is `volume`. — src/interface/editor_sections/volume_section.cpp (`VolumeSlider("volume")`, `peak_meter_left_`, `peak_meter_right_`).
- Oscilloscope can be switched to a spectrogram with a button laid over it; spectrogram range fixed at -40 dB to 0 dB. — header_section.cpp (`view_spectrogram_`, `spectrogram_->setMinDb(-40.0f)`, `setMaxDb(0.0f)`).

## 3. Oscillators and wavetables (Voice tab, "OSC 1/2/3")

- On / off switch per oscillator: parameter `osc_N_on`. — oscillator_section.cpp (`oscillator_on_ = SynthButton("osc_" + number + "_on")`).
- Wavetable display (3D view of the frames) with the wavetable's name shown at the top of the display; clicking the name area opens a popup wavetable browser (600 x 400 scaled), listing files from the Wavetables folders; the arrows beside the name step to the previous / next wavetable file. — oscillator_section.cpp (`preset_selector_` PresetSelector; `OscillatorSection::textMouseDown` -> `showPopupBrowser(... LoadSave::getWavetableDirectories(), vital::kWavetableExtensionsList ...)`; `prevClicked` / `nextClicked` -> `LoadSave::getShiftedFile`).
- The pencil icon at the bottom-right corner of the wavetable display opens the wavetable editor for that oscillator. — oscillator_section.cpp (`edit_button_` `Paths::pencil()`; `buttonClicked` -> `parent->showWavetableEditSection(index_)`).
- A small button at the bottom-left of the wavetable display cycles the view among "3D", "2D" and "SP" (spectrum). — oscillator_section.cpp (`dimension_button_`, `strings::kWavetableDimensionNames` = "3D", "2D", "SP"; the click handler steps `render_type`); synth_strings.h `kWavetableDimensionNames`.
- Dragging a wavetable frame position: click and drag vertically on the display to move the Wave Frame (the frame slider's popup shows while dragging); mouse wheel on the display moves the frame slider too. There is also a vertical WAVE FRAME slider beside the display (`osc_N_wave_frame`, 0 to 256, i.e. 257 frames). — src/interface/editor_components/wavetable_3d.cpp (`mouseDown` -> `frame_slider_->showPopup`, `mouseDrag` uses vertical delta, `mouseWheelMove` -> `frame_slider_->mouseWheelMove`); oscillator_section.cpp `wave_frame_`; synth_constants.h `kNumOscillatorWaveFrames = 257`.
- Right-click on the wavetable display: Save to Wavetables, Copy, [Paste, only if the clipboard holds a matching wavetable], (separator), Initialize, Text to Wavetable (shows "Text to Wavetable - Log in" when not signed in), Resynthesize Preset to Wavetable. — wavetable_3d.cpp `mouseDown` (`kSave "Save to Wavetables"`, `kCopy "Copy"`, `kPaste "Paste"`, `kInit "Initialize"`, `kTextToWavetable "Text to Wavetable"`, `kLogIn "Text to Wavetable - Log in"`, `kResynthesizePreset "Resynthesize Preset to Wavetable"`).
- Text to wavetable: a text box over the display with the empty-state text "Text to wavetable", a language menu (31 languages; the fallback index is 4, which by counting the code list is `en-AU`, see Unconfirmed), maximum 100 characters; it is a web request (needs login). The website says 5 requests per day for free users. — oscillator_section.cpp (`ttwt_->setTextToShowWhenEmpty(TRANS("Text to wavetable"), ...)`, `kMaxTTWTLength = 100`, `kLanguageNames`, `kLanguageCodes`, `getLanguageIndex` `kDefaultIndex = 4`); https://vital.audio ("Text-to-wavetable is a web service ... (Normally limited to 5 requests / day)").
- Dragging an audio file onto the wavetable display loads it as a wavetable, and where you drop decides the method: top 3/8 of the display = WAVETABLE (wavetable splice), middle = VOCODE, bottom 3/8 = PITCH SPLICE (labels drawn on the display while dragging). Only a single `.wav` / `.flac` etc. file (any format JUCE registers) is accepted. — wavetable_3d.cpp `updateDraggingPosition` (`kDivisionPercent = 3.0f / 8.0f`; `kWavetableSplice` top, `kVocoded` middle, `kPitched` bottom) and the texts "WAVETABLE", "VOCODE", "PITCH SPLICE"; src/interface/editor_components/audio_file_drop_source.h (`isInterestedInFileDrag`: `files.size() != 1` -> false).
- Home site wording for the same: "Turn your own samples into wavetables by using Vital's pitch-splice or vocode wavetable converter." — https://vital.audio.
- Controls, by label: PITCH group = transpose (semitones, -48 to +48; Shift-drag / Shift-scroll moves it in steps of 12 = octaves) and tune, plus a transpose-quantize button; UNISON group = voices (1 to 16), detune, detune power; PHASE group = phase and random phase; LEVEL and PAN knobs; spectral morph amount knob and distortion amount knob, each with a type name between left / right arrows; DESTINATION selector with arrows. — oscillator_section.cpp (`paintJointControl(... "PITCH")`, `"UNISON"`, `"PHASE"`, `drawLabelForComponent(g, TRANS("PAN"), ...)`, `TRANS("LEVEL")`; `transpose_->setShiftIndexAmount(vital::kNotesPerOctave)`); synth_parameters.cpp (`transpose` -48..48, `unison_voices` 1..16, `level`, `pan`).
- Unison defaults: 1 voice (= unison off); detune default 4.472 (quadratic scale 0-10); random phase default 100%; phase default 0.5 (displayed in degrees). — synth_parameters.cpp `osc_parameter_list` ("unison_voices" 1.0, "unison_detune" 4.472135955, "random_phase" 1.0, "phase" 0.5 with 360 display multiplier).
- Oscillator DESTINATION (where the oscillator's sound goes), menu names: Filter 1, Filter 2, Filter 1+2, Effects, Direct Out. Defaults: osc 1 -> Filter 1, osc 2 -> Filter 2, osc 3 -> Effects. — oscillator_section.cpp (`destination_selector_` menu loops `kNumSourceDestinations`; strings::kDestinationMenuNames); synth_strings.h `kDestinationMenuNames`; synth_constants.h `SourceDestination { kFilter1, kFilter2, kDualFilters, kEffects, kDirectOut }`; synth_parameters.cpp (defaults 1 and 3 for osc 2 and 3).
- Spectral morph types (menu text, with a separator after "None"): None, Vocode, Formant Scale, Harmonic Stretch, Inharmonic Stretch, Smear, Random Amplitudes, Low Pass, High Pass, Phase Disperse, Shepard Tone, Spectral Time Skew. On the oscillator itself the short labels show: "---", VOCODE, FORM SCALE, HARM STRETCH, INHARMONIC, SMEAR, RAND AMP, LOW PASS, HIGH PASS, PHASE DISP, SHEPARD TONE, TIME SKEW. — synth_strings.h `kSpectralMorphNames` (menu); oscillator_section.cpp `kSpectralMorphTypes` (on-panel labels).
- Distortion (phase distortion) types, as menu text: None, Sync, Formant, Quantize, Bend, Squeeze, Pulse, then "FM <- Osc" (with the number of the modulating oscillator appended, e.g. the osc it listens to), "FM <- Osc", "FM <- Sample", "RM <- Osc", "RM <- Osc", "RM <- Sample". The panel shows capitals ("---", SYNC, FORMANT, QUANTIZE, BEND, SQUEEZE, PULSE, "FM <- OSC n", ..., "FM <- SAMPLE", "RM <- OSC n", ..., "RM <- SAMPLE"). A separator follows "None" and precedes the first FM entry. — synth_strings.h `kPhaseDistortionNames`; oscillator_section.cpp `kDistortionTypes`, `getDistortionSuffix`, `isDistortionMenuSeparator`.
- Spectral morph and distortion amount knobs are bipolar (centre = zero, double-click returns to 0.5) for some types and unipolar (double-click returns to 0) for others; Squeeze, Sync, None count as bipolar distortion types in the code read (list truncated, see Unconfirmed for the full list). — oscillator_section.cpp `setupSpectralMorph`, `setupDistortion`, `isBipolarDistortionType`.
- Unison stack styles (Advanced tab, per oscillator, "STACK" selector): Unison, Center Drop 12, Center Drop 24, Octave, 2x Octave, Power Chord, 2x Power Chord, Major Chord, Minor Chord, Harmonics, Odd Harmonics. — synth_strings.h `kUnisonStackNames`; src/interface/editor_sections/oscillator_advanced_section.cpp (`stack_style_` TextSelector, `drawLabelForComponent(g, TRANS("STACK"), ...)`).
- Other Advanced-tab oscillator options: NOTE TRACK (`osc_N_midi_track`), HI-RES WAVETABLE (`osc_N_smooth_interpolation`), SPECTRAL UNISON, DETUNE RANGE, UNISON BLEND, STEREO UNISON, TABLE SPREAD, DIST SPREAD, SPECT SPREAD. — oscillator_advanced_section.cpp (`setButtonText("NOTE TRACK")`, `"HI-RES WAVETABLE"`, `"SPECTRAL UNISON"`, `drawLabelForComponent` labels).
- Predefined waveform names (the shapes the editor can start from): Sin, Saturated Sin, Triangle, Square, Pulse, Saw. — synth_strings.h `kPredefinedWaveformNames`. (Where the editor uses them is not shown in the files read.)

## 4. Sample

- A "SMP" section on the Voice tab, with its own on switch (`sample_on`, default off), level, pan, transpose, tune, transpose-quantize, destination (same five destinations as oscillators), and four icon toggles: keytrack, random phase, loop, bounce. — src/interface/editor_sections/sample_section.cpp (`SampleSection("SMP")`, `sample_level`, `sample_pan`, `sample_transpose`, `sample_tune`, `sample_destination`, `sample_keytrack`, `sample_random_phase`, `sample_loop`, `sample_bounce`, `sample_on`; `Paths::keyboard()`, `shuffle()`, `loop()`, `bounce()`).
- Clicking the sample name opens a popup browser for the Samples folders (`.wav;.flac`); prev / next arrows step through files. — sample_section.cpp `textMouseDown` (`showPopupBrowser(this, bounds, LoadSave::getSampleDirectories(), vital::kSampleExtensionsList ...)`), `prevClicked`/`nextClicked`.
- The sample can be a modulator for oscillators ("FM <- Sample", "RM <- Sample") and can feed filters through the "SMP" toggle on each filter. — synth_strings.h `kPhaseDistortionNames`; filter_section.cpp (`sample_input_` text "SMP").

## 5. Filters (Voice tab: FILTER 1, FILTER 2; plus the "FILTER" effect on the Effects tab)

- Each filter section has: an on switch (`filter_N_on`, default off); input toggles OSC1, OSC2, OSC3, SMP, and FIL2 (on filter 1) / FIL1 (on filter 2) = take input from the other filter (serial); a model/style selector with a "MODE" label showing "Model : Style"; cutoff (horizontal bar), resonance (vertical bar), blend, drive, key tracking (KEY TRK) and mix knobs; a response graph. — src/interface/editor_sections/filter_section.cpp (`osc1_input_` "OSC1", `osc2_input_` "OSC2", `osc3_input_` "OSC3", `sample_input_` "SMP", `filter_input_->setText(String("FIL") + String(3 - index))`; `drawLabelForComponent(g, TRANS("MODE"), ...)`; `"filter_" + number + "_cutoff"` etc.; `preset_selector_->setText(model, ":", style)`).
- Filter models (menu top level): Analog, Dirty, Ladder, Digital, Diode, Formant, Comb, Phaser. Opening the selector shows each model as a sub-menu of its styles; prev / next arrows walk through all model+style combinations. — synth_strings.h `kFilterModelNames`; filter_section.cpp (`PopupItems sub_options(strings::kFilterModelNames[i])`, `prevClicked`/`nextClicked`).
- Styles: Analog, Dirty, Ladder and Digital each have 5 styles: 12dB, 24dB, Notch Blend, Notch Spread, B/P/N. — synth_strings.h `kFilterStyleNames`; filter_section.cpp `getNumStyles` (5 for those four models).
- Diode has 2 styles: Low Shelf, Low Cut. Formant has 3 style names in code: "The Mouth" (vocal tract), "AIUO", "AOIE" (but `getNumStyles` returns 2 for Formant, so only the first two may be selectable; see Unconfirmed). Comb has 6: Low High Comb, Low High Flange+, Low High Flange-, Band Spread Comb, Band Spread Flange+, Band Spread Flange-. Phaser has 2: Positive, Negative. — synth_strings.h `kDiodeStyleNames`, `kCombStyleNames`; filter_section.cpp `getStyleName` / `getNumStyles`.
- Knob labels change with the model: normally DRIVE and KEY TRK; Comb shows CUT in place of DRIVE; Formant shows PEAK and SPREAD and a two-axis formant X / Y control instead of cutoff / resonance. — filter_section.cpp `setLabelText`, `showModelKnobs`.
- Filter defaults: cutoff 60 (semitone scale), resonance 0.5, mix 1.0, model 0 (Analog), style 0 (12dB), on = 0. — synth_parameters.cpp `filter_parameter_list` ("cutoff" 60.0, "resonance" 0.5, "mix" 1.0, "model" 0, "style" 0, "on" 0).
- Cutoff has an alternate display in Hz available (`setSliderHasHzAlternateDisplay`). — filter_section.cpp.
- A "FILTER" effect also exists in the effects chain (parameters `filter_fx_*`). — effects_interface.cpp (`filter_section_ = FilterSection("fx", ...)`); modulation_matrix.cpp (`{ "filter_fx_", "Filter FX", true }`).

## 6. Envelopes (ENVELOPE 1-6)

- Controls and labels: DELAY, ATTACK, HOLD, DECAY, SUSTAIN, RELEASE knobs, plus attack / decay / release curve ("power") controls and an editable graph. — src/interface/editor_sections/envelope_section.cpp (`drawLabelForComponent(g, TRANS("DELAY") ... "ATTACK" ... "HOLD" ... "DECAY" ... "SUSTAIN" ... "RELEASE")`; `attack_power_`, `decay_power_`, `release_power_`).
- Envelope 1 is shown first; it is the envelope for the level of the sound by default in the engine (not shown in the UI files read; see Unconfirmed).
- Graph gestures: drag the delay / attack / hold / decay-sustain / release nodes (left-right sets time; the sustain node also moves up-down for the level); drag a curve handle up or down to bend that segment (power); double-click a curve handle to reset its power to 0; mouse wheel zooms the time axis; the magnifying-glass icon drags to zoom and double-click on it resets zoom. — src/interface/editor_components/envelope_editor.cpp (`mouseDrag` with `setDelayX`, `setAttackX`, `setHoldX`, `setDecayX` + `setSustainY`, `setReleaseX`, `setAttackPower` etc.; `mouseDoubleClick` -> `setAttackPower(0.0f)` etc.; `mouseWheelMove` -> `zoom`); envelope_section.cpp `DragMagnifyingGlass::mouseDoubleClick` -> `magnifyDoubleClicked` -> `envelope_->magnifyReset()`.

## 7. LFOs (LFO 1-8) and Random (RANDOM 1-4)

- LFO panel: a line (point) editor; a name box with prev / next arrows and a click-to-open LFO browser (500 x 250) of `.vitallfo` files; MODE selector (sync type); FREQUENCY control with a sync selector; DELAY, STEREO, fade or smooth controls; a smooth-mode selector (FADE IN / SMOOTH); a paint-mode toggle with pattern selector; a smooth-curve toggle; grid size X / Y. — src/interface/editor_sections/lfo_section.cpp (`preset_selector_`, `drawLabel(g, TRANS("MODE"), ...)`, `TRANS("FREQUENCY")`, `"DELAY"`, `"STEREO"`, `paint_`, `lfo_smooth_`, `grid_size_x_`, `grid_size_y_`, `textMouseDown` 500x250).
- LFO mode (sync type) names: Trigger, Sync, Envelope, Sustain Envelope, Loop Point, Loop Hold (short forms: Trigger, Sync, Envelope, Sustain Env, Loop Point, Loop Hold). Default: Trigger. — synth_strings.h `kSyncNames`, `kSyncShortNames`; synth_parameters.cpp `lfo_parameter_list` "sync_type" default 0.
- LFO frequency sync options: Seconds, Tempo, Tempo Dotted, Tempo Triplets, Keytrack. Default Tempo (`"sync"` default 1.0). Tempo divisions list: Freeze, 32/1, 16/1, 8/1, 4/1, 2/1, 1/1, 1/2, 1/4, 1/8, 1/16, 1/32, 1/64. — synth_strings.h `kFrequencySyncNames`, `kSyncedFrequencyNames`; synth_parameters.cpp "sync" default 1.0, "tempo" default 7.0 (LFO).
- LFO smooth modes: FADE IN, SMOOTH. Paint patterns: Step, Half, Down, Up, Tri. — synth_strings.h `kSmoothModeNames`, `kPaintPatternNames`.
- LFO point editor gestures: double-click empty space adds a point; double-click a point removes it (the first and last cannot be removed); double-click a curve handle resets its power (Shift-double-click resets all); drag a point to move it; Alt held while dragging a point changes how it moves (the code passes `!e.mods.isAltDown()` as the last argument of `movePoint`; I take that to be grid snapping, unconfirmed); Cmd held toggles paint mode temporarily; mouse wheel changes the grid X size (or the paint pattern when painting). ## 8. Modulation: how to create one (the assignment workflow)

Exact steps in the code (everything below from src/interface/editor_components/modulation_button.cpp and src/interface/editor_sections/modulation_manager.cpp):

1. Sources are small buttons labelled by name: ENV 1-6, LFO 1-8, RANDOM 1-4, MACRO 1-4 (the macro button has empty text and sits under the macro knob), and the keyboard sources NOTE, VELOCITY, LIFT, OCT NOTE (note in octave) in one row and PRESSURE (aftertouch), SLIDE, STEREO, RANDOM in another. — modulation_interface.cpp (`kKeyboardTopModulationStrings` = "note", "velocity", "lift", "note_in_octave"; `kKeyboardBottomModulationStrings` = "aftertouch", "slide", "stereo", "random"; `overrideText("OCT NOTE")`, `overrideText("PRESSURE")`); modulation_matrix.cpp `getMenuSourceDisplayName` / `getUiSourceDisplayName` (names are the code name capitalised and upper-cased, "control_" removed, aftertouch -> "After Touch"); macro_knob_section.cpp (`macro_source_->overrideText("")`).
2. Press the mouse on a source button and drag it out of the button: as soon as the pointer leaves the button, "modulation map" mode starts (cursor becomes a dragging hand, a line is drawn from the button to the pointer) and every modulatable knob / slider that is currently visible in an active section is highlighted as a target. — modulation_button.cpp `mouseDrag` (`!getLocalBounds().contains(...)` -> `startModulationMap`, `setMouseCursor(MouseCursor::DraggingHandCursor)`); modulation_manager.cpp `startModulationMap` (`destination.second->setVisible(should_show)` with `model->isShowing() && model->getSectionParent()->isActive()`).
3. Move the pointer over the target knob: the modulation is made at once, temporarily, and the amount overlay shows; this is the "preview before committing" behaviour. Moving off the knob before letting go removes that temporary modulation again. — modulation_manager.cpp `modulationDragged` -> `modulationDraggedToComponent` (`connectModulation(source_name, name)`, `showModulationAmountOverlay`), `clearTemporaryModulation`; https://vital.audio ("Vital gives you a preview of the modulation before committing").
4. Release the mouse over the knob to keep it: `endModulationMap()` keeps the connection, hides the destination highlights, and positions the amount knob. — modulation_manager.cpp `endModulationMap`.
5. Starting amount: the amount fills the room above the knob's current setting (`1 - current position`), but never less than 0.25. If any modifier key (Shift, Ctrl, Alt, Cmd) is held while dragging, the modulation is made bipolar and the amount is `2 * min(room above, room below)`, again at least 0.25. Pressing or releasing a modifier while hovering changes this live. — modulation_manager.cpp `modulationDraggedToComponent` (`modulation_amount = 1.0f - percent; if (bipolar) modulation_amount = std::min(modulation_amount, percent) * 2.0f; modulation_amount = std::max(modulation_amount, kDefaultModulationRatio);` with `constexpr float kDefaultModulationRatio = 0.25f;`), `modulationDragged` (`bool bipolar = e.mods.isAnyModifierKeyDown();`), `setTemporaryModulationBipolar`.
6. Mouse wheel while dragging adjusts the new connection's amount. — modulation_manager.cpp `modulationWheelMoved` (forwards to `selected_modulation_sliders_[index]->mouseWheelMove`).
7. Limit: if all 64 connections are used, dragging does not start. — modulation_manager.cpp `startModulationMap` (`if (!hasFreeConnection()) return;`), synth_constants.h `kMaxModulationConnections = 64`.
- Clicking (not dragging) a source button selects it ("active modulation"): the amount knobs for all of its connections appear next to their destination knobs; clicking elsewhere (focus lost) deselects it. — modulation_button.cpp `mouseDown` (`setActiveModulation(true)`, `modulationSelected`), `focusLost`; modulation_manager.cpp `modulationSelected`, `makeCurrentModulatorAmountsVisible`, `modulationLostFocus`.
- Selecting a destination knob that is modulated (clicking it) selects the modulation source connected to it and shows that source's amount knob. — modulation_manager.cpp `mouseDown(SynthSlider*)` (`modulationSelected(modulation_buttons_[connection->source_name])`).
- An unused source button shows drag-and-drop arrows when the mouse hovers over it (only when it has no connections). — modulation_button.cpp `mouseEnter` (`show_drag_drop_ = ... getSourceConnections(...).empty()`), constructor `Paths::dragDropArrows()`.
- Changing the amount later: with the source selected, drag the small amount knob that appears beside / above / below the destination knob (position depends on the destination's modulation placement); the cursor is hidden and moves unbounded while you drag it, and returns to where you started when you let go. Holding Cmd while dragging = slow / fine (x0.1); Alt-click opens the text-entry box. — modulation_manager.cpp `ModulationAmountKnob::mouseDown`/`mouseUp` (`source.enableUnboundedMouseMovement(true)`, `hideCursor`, `setScreenPosition(mouse_down_position_)`), `makeCurrentModulatorAmountsVisible`; synth_slider.cpp (`kSlowDragMultiplier = 0.1f`, `isCommandDown()`, `isAltDown()` -> `showTextEntry()`; ModulationAmountKnob derives from SynthSlider).
- Amount knob right-click menu: Remove; Bypass / Unbypass; Make Bipolar / Make Unipolar; Make Stereo / Make Mono; (separator); Learn MIDI Assignment; Clear MIDI Assignment (if mapped); Enter Value. Middle-click toggles bypass. — modulation_manager.cpp `ModulationAmountKnob::mouseDown` (`options.addItem(kDisconnect, "Remove")`, `kToggleBypass`, `kToggleBipolar`, `kToggleStereo`, `kArmMidiLearn`, `kManualEntry`; `isMiddleButtonDown()` -> `toggleBypass()`).
- Double-click on an amount knob (the connection's knob, via the modulation manager) removes that modulation connection. — modulation_manager.cpp `ModulationManager::doubleClick(SynthSlider*)` -> `removeModulation(connection->source_name, connection->destination_name)`.
- Removing modulations from the source: right-click a source button that has connections -> "Disconnect from <destination>" for each, and "Disconnect all" if more than one. — modulation_button.cpp `mouseDown` (`std::string disconnect = "Disconnect from "`, `options.addItem(kDisconnect, "Disconnect all")`).
- Removing modulations from the destination: right-click a modulated knob -> "Disconnect from <source>" for each and "Disconnect all modulations" if more than one. — synth_slider.cpp `createPopupMenu` (`"Disconnect from "`, `kClearModulations "Disconnect all modulations"`).
- Dragging a source onto the amount knob of an existing modulation (a "hover slider") connects that source to the amount of the other modulation, i.e. one modulation modulating another's depth. — modulation_manager.cpp `modulationDraggedToHoverSlider`, `addAuxConnection`. (Only how it works in code; the visible look is not confirmed.)
- Website description: "Modulate Vital's controls with a fast, drag and drop workflow." — https://vital.audio.
