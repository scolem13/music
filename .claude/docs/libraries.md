- Mode & Raga Library (`tools/mode-library.qmd`, `apps/shared/mode-library.js`, global ModeLibrary; the Rhythm Library's melodic twin): 52 cards, each feature tagged fixed (like a clave) / chosen (a pool, like bebop alterations, 🎲 picks) / leans on / free; Hindustani = Garland vol. 5 Fig. 6 aroh-avaroh as printed (23 ragas, read from page images), Karnatak 72-mela builder from Venkatamakhi's rule, maqam structure from MaqamWorld prose (cents are quarter-tone notation), pathet (Wikipedia), in / yo / hirajōshi, church modes, bebop / 7alt / dominant scales. Sources `scripts/sources/mode-library.py`; gaps under "Not here yet". Tests `node tests/mode-library/mode-library.test.js`, `tests/mode-library/mode-library.cdp.js` (both `NEG=1` must fail).
- Sargam, Swara and Jianpu (`tools/alt-notation.qmd`, `apps/shared/alt-notation.js`, global AltNotation; needs AbcCore): any one-line ABC tune (collection search, `?tune=<%%id>`, or typed) drawn as Hindustani Bhatkhande-style sargam in a tāl grid, Carnatic swara letters against a tāḷa, or jianpu. A simple version: the beat = M: denominator, no ornaments, no repeats, Sa = home note, jianpu 1 = do of the key signature; limits in its header. Tāl shapes from the Rhythm Library. Tests `node tests/alt-notation/alt-notation.test.js` (reads every collection tune), `tests/alt-notation/alt-notation.cdp.js` (both `NEG=1` must fail).
