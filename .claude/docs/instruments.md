# Instrument lessons: sax, brass, Kjos W74 band instruments

(Moved from the root CLAUDE.md 2026-11-27.)

- Saxophone (`lessons/saxophone.qmd`: history, parts, embouchure, tone problems, tuning; interactive fingering chart, build-a-fingering quiz, trill chart) and Sax Patterns by Ear (`practice/sax-patterns-by-ear.qmd`, `apps/patterns/ear-sax.js`: the piano ear tool with fingering diagrams, mic input via PitchDetect). Chart data and drawing `apps/shared/sax/sax-chart.js` (header lists what is unverified), widgets `sax-page.js`, sources `scripts/sources/saxophone.py`. Tests `node tests/sax/sax-chart.test.js`, `tests/sax/sax.cdp.js`
- Trumpet and Tuba fingering charts (`lessons/brass-fingerings.qmd`: how valves work, explorer with toggleable staff / letter names / concert pitch, press-valves-to-find-notes builder and quiz, chart table; data redrawn from two StepWise charts, one fingering gives many partials). Chart data `apps/shared/brass/brass-chart.js` (header lists what is unverified, e.g. tuba key not printed), widgets `brass-page.js`, sources `scripts/sources/brass.py`. Tests `node tests/brass/brass-chart.test.js`, `tests/brass/brass.cdp.js`
- Band instruments from the teacher's Kjos "W74" guide (2026-11-06; scan in ../fingering-charts, book unidentified): lessons flute, oboe, clarinet, bassoon, trumpet, horn, trombone, euphonium, tuba, electric-bass, percussion, snare-drum, each with its chart in `apps/shared/<inst>/` (header lists what is unverified), sources `scripts/sources/<inst>.py`, tests `tests/<inst>/` (cdp tests run on their own harness pages, `--site`/`RENDERED=1` for the real render). Patterns by Ear for flute, clarinet, horn, bass (`apps/patterns/ear-*.js`). Not in the scan: timpani, mallets, cymbals.
